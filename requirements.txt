# STACK NOTE (Python 3.14 on Intel macOS): there are no cp314 wheels for torch
# or onnxruntime, and faiss-cpu ships only a source tarball. So instead of
# sentence-transformers + FAISS this build uses:
#   * model2vec   - static distilled embeddings, numpy-only, no torch, free
#   * NumpyIndex  - exact cosine over a ~308x256 matrix. FAISS IndexFlatIP does
#                   the same brute-force scan, so an ANN index buys nothing at
#                   this corpus size. Both sit behind core.ports.VectorIndex,
#                   so FaissIndex can be added without touching callers.
